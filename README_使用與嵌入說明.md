# 八里新育｜3D 學習步道群島與課程推手（HEART 政策島風格改寫版）

本專案已將您原有的 2D 學習步道地圖與課程推手系統，全面升級為類似 `puma.taipei/heart-island` 的 **動態 3D 六角浮空群島互動網站**。

---

## 📁 檔案結構說明

1. **`index.html`（單一完整 HTML 獨立嵌入版／本地預覽檔）**
   - 已將 **14 座 3D 學習步道浮空島嶼**、**跨島連結光軌**、**日夜光影系統**、**B.A.L.I. 新育四力篩選** 以及 **「✨ 課程設計團隊（課程推手）」** 完整打包成單一 HTML 檔案。
   - **本地預覽**：直接在電腦上雙擊 `index.html` 即可用瀏覽器開啟體驗。
   - **直接嵌入 Google 協作平台**：複製 `index.html` 的全部內容，在 Google 協作平台選擇 **「插入」→「嵌入」→「嵌入程式碼」** 貼上即可！

2. **`GAS專案/` 資料夾（維持原 Google Apps Script 架構版本）**
   - **`程式碼.gs`**：對應您原本的 GAS 後端程式，自動從 Google 雲端硬碟 `新育幸福學校` 資料夾讀取 `瀏覽標籤與連結`（工作表 `Locate`）與 `designer`（工作表 `people`）。
     - **效能大幅提升**：移除原本每次載入皆需從雲端硬碟讀取並轉換 300KB 底圖 (`school-map.jpg`) 的瓶頸，改由 Three.js 即時渲染 3D 群島，載入速度提升 5 倍以上。
     - **新增 JSON API 支援 (`?action=api`)**：讓獨立嵌入 Google 協作平台的 `index.html` 也能自動向 GAS 同步最新試算表資料與課程推手名單。
   - **`Ln_Trails.html`**：GAS 模塊 A（3D 學習步道群島前端）。
   - **`Team.html`**：GAS 模塊 B（八里新育・課程推手前端）。

## 🚀 如何嵌入 Google 協作平台（Google Sites）？

### 方式一：直接貼上「嵌入程式碼」（推薦，速度最快、無 GAS 頂部灰色提示列）
1. 用記事本或 VS Code 打開 [`index.html`](./index.html)，按 `Ctrl + A` 全選並複製全部程式碼。
2. 進入您的 **Google 協作平台** 編輯畫面。
3. 點擊右側選單的 **「插入」→「嵌入」→ 切換到「嵌入程式碼 (Embed code)」** 分頁。
4. 貼上剛剛複製的 HTML 程式碼，點擊「下一步」→「插入」，並將嵌入區塊拉寬至滿版即可！

### 方式二：更新您原有的 Google Apps Script (GAS) 專案
1. 打開您原本的 Google Apps Script 專案。
2. 將 [`GAS專案/程式碼.gs`](./GAS專案/程式碼.gs) 的內容覆蓋至原本的 `程式碼.gs`。
3. 將 [`GAS專案/Ln_Trails.html`](./GAS專案/Ln_Trails.html) 的內容覆蓋至原本的 `Ln_Trails.html`。
4. 將 [`GAS專案/Team.html`](./GAS專案/Team.html) 的內容覆蓋至原本的 `Team.html`。
5. 點擊右上角 **「部署」→「管理部署作業」→ 點擊鉛筆圖示「編輯」→ 版本選擇「新版本」→「部署」**。
6.若使用 `index.html` 獨立嵌入版且希望自動讀取最新試算表，只需確定 `index.html` 內的 `window.BALI_GAS_EXEC_URL` 為您的 GAS `/exec` 網址即可。

## 📊 Google 試算表 (`瀏覽標籤與連結` -> `Locate`) 擴充欄位支援

除了您原本的欄位（`名稱`、`X (px)`、`Y (px)`、`網址`、`長度`、`color`、`底色`、`字體顏色`、`呈現`）100% 原生相容之外，若您未來想在試算表中自訂島嶼介紹，只需在標題列自由新增以下**選填欄位**即可直接覆寫預設值：

| 選填欄位標題 | 說明與範例 |
| :--- | :--- |
| **`分類`**（或 `願景`） | 填入 `B`、`A`、`L`、`I`（可複選如 `B,I`），對應 **B 活力堅毅**、**A 國際文史**、**L 心靈共融**、**I 創客永續** |
| **`簡介`**（或 `說明`） | 點擊島嶼時彈出卡片上的步道主題介紹文字 |
| **`亮點`**（或 `特色`） | 以頓號、逗號或換行分隔的課程亮點（例如：`基礎投打訓練、戰術與團隊合作、運動防護與品格修練`） |
| **`主題`**（或 `模型`） | 指定島嶼 3D 模型風格（`baseball`, `archery`, `prevention`, `multicultural`, `voyage`, `redbrick`, `maker`, `emotion`, `filial`, `model`, `inclusive`, `mv`, `virtue`, `green`） |
