# 八里新育｜3D 學習步道群島與課程推手 (BALI Learning Trail Archipelago)

將「八里新育 學習步道與課程推手」Google Apps Script (GAS) 網站升級為動態 3D 浮空群島互動網站，並支援一鍵嵌入 **Google 協作平台 (Google Sites)** 與 **GitHub Pages**。

## ✨ 網站特色
- **14 座主題 3D 浮空六角島嶼**：每條學習步道皆有專屬的微縮立體建築與小學生動態情境劇場（棒球投打、射箭靶心、地震避難三步驟、各國多元文化共舞、雙語生活對話、御大禮紀念碑與紅磚教室導覽、創客永動機械、情緒和平互動、長者奉茶關懷、模型組裝、推輪椅無障礙同行、MV 舞台、校門導護與資源回收、綠能風車）。
- **3D 吉祥物「八里柚寶」與小學生漫步**：以 `maimrole.png` 打造的 3D 玩偶領航員與 28 位各年級小學生在群島與跨島拱橋間散步互動。
- **淡水河口與淡江大橋遠景**：背景兩座島嶼之間呈現單塔不對稱斜張橋「淡江大橋」與動態行駛的淡海輕軌列車，支援晨曦、白晝、黃昏、星夜一日光影變化。
- **B.A.L.I. 新育四力篩選**：
  - **B｜活力堅毅(Body & Brave)**
  - **A｜國際文史(Art & Culture)**
  - **L｜心靈共融(Love & Care)**
  - **I｜創客永續(Innovation & Green)**

## 📂 專案結構
- `index.html`：獨立單檔完整版（可直接透過 GitHub Pages 發布，或貼入 Google 協作平台「嵌入程式碼」）。
- `GAS專案/`：Google Apps Script 雙模塊版本（`程式碼.gs`、`Ln_Trails.html`、`Team.html`），可直接連接 Google 雲端硬碟試算表。
- `maimrole.png`：八里柚寶吉祥物原圖素材。
